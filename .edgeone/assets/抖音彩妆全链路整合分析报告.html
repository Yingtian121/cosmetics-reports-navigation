「底妆投资品 vs 色彩消耗品」支付意愿分化

ASP 阶梯揭示了用户的核心支付逻辑：底妆（¥92）和卸妆（¥72）作为功能性刚需，用户愿意支付高溢价；而眼妆（¥29）和工具（¥19）作为色彩/工具消耗品，ASP 低但更新频率高。修容（¥40）处于中间位置——既不是最高投资品，也不是最低消耗品，而是「色彩进阶品」，这解释了其中价带（¥30-60）品牌占 55.6% 的市场结构。

口径差异的整合处理原则

① 识别口径差异来源（时间范围、统计单位、对比基数）；
② 保持口径标注——引用数据时必须注明来源报告和口径；
③ 推算验证——通过年度化、占比推算等方法交叉验证数据合理性；
④ 标注置信度——口径完全一致的数据可直接使用，口径有差异的需标注推算过程。

08 整合洞察与战略建议
基于全链路整合分析，提出跨层级、跨品类的战略洞察

核心洞察 1：增长动能的层级传递

  • 大盘增速 +29.9% 的主要动能来自面部（174.76亿，+33%）和工具（26.06亿，+37.1%）
  • 面部增速的核心引擎是修饰层（+56.5%），而非底妆层（+29%）——增长动能从底妆向修饰转移
  • 修容作为修饰层核心品类（占修饰层58.9%），其 +21.5% 增速虽低于修饰层均值，但品牌层 BABI +1922% 表明品牌替换比品类增长更剧烈
  • 动能传递路径：大盘增长 → 底妆饱和 → 修饰层爆发 → 修容品牌洗牌

核心洞察 2：ASP 阶梯决定竞争逻辑

  • 高 ASP 品类（底妆¥92、卸妆¥72）竞争逻辑 = 功能/品质驱动，品牌壁垒高
  • 低 ASP 品类（工具¥19、眼妆¥29）竞争逻辑 = 量/频次驱动，价格敏感度高
  • 修容（¥40）处于中间地带——既有品质竞争（OUT-OF-OFFICE领跑），也有品牌升级突破（BABI ASP+140%、+1922%）
  • 中价带（¥30-60）占55.6% 意味着修容尚未形成明确的品质/价格分化，竞争格局仍在演化中

核心洞察 3：短视频内容适配性是增长的隐藏变量

  • 增速最高的品类/品牌普遍具备「效果对比可见性高 + 教程价值高 + ASP低」的特征
  • 修容：强对比（前后效果明显）+ 强教程（修容手法教学）+ 低ASP（¥40）→ +39% 增速
  • BABI：品牌定位升级（ASP ¥27→¥65，+140%）+ 先升价后放量 → +1922% 增速
  • 对比：粉底液（弱对比 + 高ASP ¥92）→ 仅 +26%，口红（弱教程 + 中ASP ¥52）→ 仅 +1%
  • 战略含义：新品类/新品牌的冷启动应优先评估其短视频内容适配性

核心洞察 4：集中度下降 ≠ 品类衰退

  • 修容 CR5 从 64.7% 降至 53.8%，但品类整体增速 +21.5%——集中度下降伴随着品类扩张
  • 这意味着新进入者（如 BABI）在扩大品类蛋糕的同时蚕食了头部份额
  • 对比：口红 +1% 增速 + 高集中度 = 成熟品类的零和博弈
  • 战略含义：集中度下降的品类是进入窗口期，集中度上升+低增速的品类是退出信号

核心洞察 5：品类联动决定品牌延伸方向

  • 修容+高光+腮红构成修饰层三件套，三品类增速均>39%，存在协同效应
  • 气垫→上妆工具→卸妆构成使用链，品牌可沿链条延伸
  • 唇笔+唇釉的形态迁移表明同品类内形态创新比跨品类延伸更有效
  • 战略含义：品牌延伸应优先选择联动效应强的品类组合，而非随机进入高增速品类

整合分析的终极结论

7 份报告的系统性整合揭示了一个完整的彩妆增长图谱：

大盘 268.48 亿、+29.9% 的高增长并非均匀分布，而是沿着 「底妆饱和 → 修饰爆发 → 工具放量」 的路径传递。面部彩妆以 65.1% 的体量主导大盘，但其内部增长引擎已从底妆层（+29%）转向修饰层（+56.5%）。

修容作为修饰层核心品类（7.25亿，占修饰层58.9%），是观察「品类→品牌」竞争演化的最佳窗口。其 CR5 从 64.7% 降至 53.8%，但品类增速 +21.5%——集中度下降伴随品类扩张，意味着新品牌正在做大蛋糕的同时蚕食头部份额。

品牌层的竞争逻辑由 ASP 阶梯和品牌势能共同决定。BABI 以品牌定位升级（ASP 从¥27升至¥65，+140%）+ 先升价后放量的路径实现 +1922% 增速，验证了「品牌势能驱动 > 价格优势驱动」的修容品类竞争逻辑；而 forever key ASP 稳定在¥36 但购买人数跌81%，遭遇 -28% 下滑，验证了「缺乏品牌势能升级 = 份额流失」的反面。

整合分析的核心价值在于：单一报告只能看到某一层级的局部图景，而系统性整合能揭示跨层级的增长动能传递、结构性规律验证和品类联动关系，从而为战略决策提供从宏观到微观的全链路视角。
