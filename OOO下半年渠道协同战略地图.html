OOO 7月渠道协同策略方向

市场端打底 × 渠道双引擎 · 三端协同 · 渠道协同 · 各展所长
覆盖端口：市场端 / 自播 / 达播 / 达短 / 种草 | 战略周期：2026年7月起 | 依据：6-7月渠道表现复盘
战略出发点
6-7月复盘显示：达播和自播在货盘机制上容易对冲，形成内部的无效损耗；同时下半年达播、达短、自播（内容电商）三渠道均面临巨大生意压力，品牌大爆品也面临增长瓶颈。结论：市场端以品牌故事打底、营造全渠道营销氛围，渠道端协同互补、各展所长，两条腿走路——一条腿守住修容笔基本盘（自播×达短×种草协同），另一条腿靠新品打爆能力开拓新战场（达播×达短共振）。
市场端 · 品牌故事引擎（全渠道氛围底座）
大爆品面临瓶颈期，市场端不再追求单纯的曝光量级，而是讲好故事、引发心智共振，为所有销售渠道做好基础且重要的营销氛围
市场端 · 营销氛围引擎
讲好 OOO 品牌故事 / 修容笔的故事
触发背景：品牌大爆品面临瓶颈，增长不能只靠爆品带货，需要品牌故事提供新的叙事势能

标杆目标 · 对标 25年 Jaden 式传播事件
打造品牌&产品心智导向的长效营销传播事件
持续塑造品牌&产品故事，为品牌获取长效流量，为全渠道供给品牌势能与内容素材
✗ 不是
短时间的曝光量级增加——流量来得快去得也快，对品牌资产无沉淀。
✓ 而是
通过 OOO 产品新妆容 / 品牌升级的故事，引发核心目标人群的心智共振，塑造更具品牌力的营销传播事件，为品牌获取长效流量——为各销售渠道做好基础且重要的营销氛围。
市场端 × 渠道端协同
市场端造势（品牌故事事件）→ 种草 / 达短承接内容放大 → 自播 / 达播承接转化——市场端为渠道双引擎持续供给品牌势能，让所有渠道的营销动作建立在统一的品牌叙事之上。
核心战略：渠道双引擎 · 两条腿走路
在市场端品牌氛围的底座上，两个引擎并行推进，互不冲突、互为支撑，共同支撑下半年三渠道生意目标

第一条腿：种草 → 达短 → 自播 协同收割
修容笔：达短 + 种草做前端人群种草与心智植入，为自播导流；自播专注承接转化

承接转化——承接达短 + 种草带来的流量与心智，稳定转化、完成成交
引擎二 · 新品增长极
第二条腿：达播 × 达短 新品打爆，开拓新战场
修容笔以外的高潜力类目：达播做新品的"大而多"，达短与其协同共振，下半年集中新品打爆

新品爆发引擎——修容笔大专场做少做精；其它高潜力类目做大做多，集中资源打爆新品
⟷ 协同共振
达短
新品放大器——在其它高潜力类目与达播形成协同共振，共同打爆新品
端口定位划分：各司其职
市场端打底 + 四个销售渠道明确分工——谁造势、谁做心智、谁做曝光、谁做转化、谁做爆发
端口角色定位修容笔（基本盘）职责新品（增长极）职责

自播 转化收割主阵地 承接达短 + 种草导流，稳定转化成交，守住修容笔基本盘 承接达播新品打爆后的热度与需求
达播 新品爆发引擎 修容笔大专场做少做精（避免与自播同盘竞争） 其它高潜力类目做大做多，集中新品打爆
达短 前端种草 + 放量放大器 前端人群种草、心智植入；保利润前提下放量曝光，为自播导流 与达播协同共振，共同打爆高潜力类目新品
种草 心智植入前端 修容笔前端人群种草，心智进一步植入 （视新品节奏协同）
渠道协同机制：避免货盘内部竞争
核心问题：6-7月达播与自播在货盘机制上容易对冲，形成内部的无效损耗——需从机制上规避
① 货盘差异定位
修容笔以自播为主力渠道承接转化，达播收缩修容笔专场（少而精），从货盘机制上避免两个渠道抢同一盘生意。
② 渠道优势发挥
修容笔转化以自播为主力、种草导流以达短 + 种草为主力、爆发打新以达播为主力——每个渠道只做自己最擅长的事，不越位、不重复。
③ 战场错位开辟
为其它高潜力类目新品增加对应资源投入，达播 + 达短协同打爆，打开增量空间。
下半年落地节奏
市场端造势与渠道双引擎并行推进，分阶段卡位
立即可做 · 协同路径跑通 + 品牌故事企划
修容笔启动「种草 → 达短 → 自播」导流链路；达播修容笔专场收敛为少而精；市场端启动品牌故事（新妆容 / 品牌升级）企划，明确对标 25年 Jaden 式事件的目标人群与心智诉求。
7-9月 · 市场造势 + 双引擎并行
引擎一：达短 + 种草持续为自播导流，巩固修容笔基本盘；引擎二：达播在其它高潜力类目排兵布阵，与达短协同共振试水新品；市场端：首发品牌故事事件，为全渠道营造营销氛围。
9-11月 · 集中新品打爆 + 品牌事件共振
达播 + 达短集中资源打爆高潜力类目新品，卡位双11前窗口；市场端以品牌升级 / 新妆容故事第二波事件共振，为打爆提供叙事势能。
全年目标 · 三渠道各自达成
达播 / 达短 / 自播在各自优势位完成下半年生意目标；市场端沉淀品牌资产——渠道协同、各展所长，市场 × 渠道三端走完整年。
